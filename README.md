Потапов Максим Константинович МБС 601 Последняя лабораторная номер 3, мой вариант был 1, текст задачи: Парсер файла настроек (.ini конфиг) 
В input.txt записаны настройки игры в формате ключ=значение (например, difficulty=hard, rain_chance=40), пустые строки и комментарии, начинающиеся с символа #. Программа должна проигнорировать пустые строки и комментарии, разделить остальные строки по символу =, проверить, что ни ключ, ни значение не пустые, и вывести чистую таблицу настроек в формате Параметр: [ключ] | Значение: [значение], а в конце указать количество успешно считанных настроек и количество отброшенных строк. 
Пока что настройки никак не влияют на геймплей (можете реализовать по желанию)
